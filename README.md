Forma — 3D Model Editor

Forma is an interactive, web-based 3D model editor that allows users to effortlessly construct, manipulate, and organize 3D scenes directly in their browser. Built with a modern web tech stack, it provides intuitive tools for real-time asset transformation and direct file exporting.

🚀 Features





Interactive 3D Canvas: Orbit, pan, and zoom seamlessly through a dynamic 3D viewport.



Object Manipulation: Select, move, rotate, and scale 3D objects with precise transform controls.



Keyboard Shortcuts: Fast workflow execution via dedicated hotkeys.



Scene Outliner: Track and manage object hierarchies and properties easily.



Seamless Export: Save and download your completed scenes straight to .glb format.

📦 Getting Started

Follow these steps to run the project locally:

1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/forma-3d-editor.git
cd forma-3d-editor



2. Install Dependencies

npm install
# or
yarn install



3. Run the Development Server

npm run dev
# or
yarn dev

Open http://localhost:5173 (or the local port provided in your terminal) in your browser to view the application.
